## 🚀 COMMANDES RAPIDES (10 min)

### 1. Configurez Git
```powershell
git config --global user.name "Votre Nom"
git config --global user.email "votre@email.com"
git init
```

### 2. Créer un repo GitHub
- Allez sur [github.com](https://github.com)
- Cliquez **`+`** → **"New repository"**
- Nommez-le: `simcompanies-scanner`
- Publiquez-le ✅

### 3. Pousser votre code
```powershell
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/VOTRE_USERNAME/simcompanies-scanner.git
git push -u origin main
```

### 4. Déployer sur Streamlit Cloud
- Allez sur [share.streamlit.io](https://share.streamlit.io)
- **Sign in with GitHub**
- Cliquez **"New app"**
- Sélectionnez votre repo + `streamlit_app.py`
- **Deploy** ✅
